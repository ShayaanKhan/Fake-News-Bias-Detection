# Fake News & Bias Detection

> **Note:** This project was initially developed in 2022. This repository is being uploaded retrospectively.

## Overview

NLP-based classification system for detecting fake news and media bias in text. Trained classification models using traditional machine learning approaches with a focus on textual feature analysis for credibility detection.

## Key Features

- Text classification using Support Vector Machine (SVM) and Naive Bayes
- Analysis of textual features for credibility and bias detection
- Preprocessing pipeline for NLP tasks

## Technical Skills

- NLP
- Classification
- Python
- Scikit-learn
